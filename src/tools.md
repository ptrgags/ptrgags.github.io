Sometimes I make oddly-specific tools to help with my creative endeavors.

## Printable Templates

- [Mini Foldable Zine Templates](./tool/zine-template/) - Templates for 1-page foldable zines where the pages are trading-card size.

## Music Tools

- [MIDI File Summary](./tool/midi-summary/) – Summarize the contents of a MIDI file (music note data). This is handy for checking metadata like time signature, tempo, and program numbers (i.e. which instruments are used).
- [MIDI Channel Splitter](./tool/midi-channel-splitter/) - Split MIDI messages into separate tracks by channel.
